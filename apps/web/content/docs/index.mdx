Kavach attacks and hardens **DiwaliMart Support**, a tool-using support bot with four mock tools and fake customers. Seven agents share one room: three attack, three defend, one keeps score. Breaches are detected by code from the bot's tool-call log, and a patch is approved only if the exploits stop working **and** at least 90% of normal customer requests still succeed.

## Run it offline

No keys needed. Scripted agents and a scripted target run the whole loop. You need Node 22+, pnpm 10 and [uv](https://docs.astral.sh/uv/).

```bash
git clone https://github.com/harshbhx/kavach.git && cd kavach
pnpm install
pnpm dev:offline     # API :8000, dashboard :5173, this site :3000
```

Open the dashboard at http://localhost:5173 and press **Start live run**, or pick `sample_simulated_run.jsonl` and press **Replay**. The sample is an offline run and is labelled as simulated. You can also watch it in the browser with no backend at [/dashboard?demo=sample](/dashboard/?demo=sample).

## Run it for real

<Steps>
<Step>

### Connect Lyzr and Band

```bash
pnpm bootstrap
```

The setup wizard asks for your Lyzr API key and user ID, your Band user API key and a model key. It creates the seven Lyzr agents from `prompts/agents/`, registers the seven Band agents, writes `.env` and `agent_config.yaml` (both gitignored) and checks every connection. Run it again with `make -C backend check-setup` to re-check. Details for each sponsor are in [Sponsor integrations](/docs/sponsors).

</Step>
<Step>

### Check the target is breakable

```bash
make -C backend probe     # needs >= 50% breach rate on guardrail v1
```

If the target model refuses too much, pick a weaker `TARGET_MODEL` in `.env`.

</Step>
<Step>

### Start a run

```bash
pnpm dev     # API + target bot + dashboard + site
```

Press **Start live run** on the dashboard. Every run is saved to `runs/<run_id>.jsonl` and can be replayed; the audit report is at `runs/<run_id>.report.md`.

</Step>
<Step>

### Record the demo

```bash
pnpm demo                          # retries until round 1 is breached, a patch is vetoed and utility holds
pnpm --filter @kavach/web video    # films the site and the run: runs/video/kavach-demo.mp4
```

`pnpm demo` saves `runs/demo_run.jsonl` and fills the results table in the README.

</Step>
</Steps>

## Repository layout

| Path | What's there |
| --- | --- |
| `backend/` | Python API: target bot, scoring, agents, orchestrator, Lyzr and Band clients, setup wizard |
| `apps/dashboard/` | The live dashboard (Vite, React, shadcn/ui, Magic UI, React Bits, Aceternity) |
| `apps/web/` | This site: landing page and docs (Next.js + Fumadocs) |
| `packages/brand/` | The Guardrail K logo and design tokens |
