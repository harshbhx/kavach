Kavach attacks and hardens **DiwaliMart Support**, a tool-using support bot with four mock tools and fake customers. Seven agents share one room: three attack, three defend, one keeps score. Breaches are detected by code from the bot's tool-call log, and a patch is approved only if the exploits stop working **and** at least 90% of normal customer requests still succeed.

## Run it offline

No keys needed. Scripted agents and a scripted target run the whole loop.

```bash
git clone https://github.com/harshbhx/kavach.git && cd kavach

# API with fake brains and an in-process fake target
cd backend && uv sync
BRAIN_PROVIDER=fake BAND_ENABLED=false TARGET_MODEL=fake TARGET_URL=inprocess FAKE_DELAY_S=1 make api

# second terminal, repo root: the dashboard on http://localhost:5173
pnpm install && pnpm dev:dashboard
```

Press **Start live run**, or pick `sample_simulated_run.jsonl` and press **Replay**. The sample is an offline run and is labelled as simulated.

## Run it for real

<Steps>
<Step>

### Add your keys

```bash
cp .env.example .env                              # Lyzr key + 7 agent IDs, model key, Band settings
cp agent_config.example.yaml agent_config.yaml    # 7 Band agent IDs + API keys
```

The seven agent prompts live in `prompts/agents/`. Paste each into a Lyzr Studio agent. Setup for every sponsor is in [Sponsor integrations](/docs/sponsors).

</Step>
<Step>

### Check the target is breakable

```bash
cd backend
make probe                                  # needs >= 50% breach rate on v1
uv run python ../scripts/band_setup.py      # checks the 7 Band identities, posts a test message
```

</Step>
<Step>

### Start a run

```bash
make target     # DiwaliMart target on :8001
make api        # Kavach API on :8000
pnpm dev:dashboard
```

Every run is saved to `runs/<run_id>.jsonl` and can be replayed from the dashboard. The audit report is at `runs/<run_id>.report.md`.

</Step>
</Steps>
