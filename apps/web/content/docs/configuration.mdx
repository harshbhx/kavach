Kavach reads its settings from `.env` at the repo root. `pnpm bootstrap` writes it for you; to do it by hand, copy `.env.example` to `.env`. Both `.env` and `agent_config.yaml` (the Band identities) are gitignored, so keys never reach the repository.

## Three ways to run

<Tabs items={['Offline', 'Live', 'Replay']}>
<Tab value="Offline">

```bash
pnpm dev:offline
```

Scripted agents, a scripted bot running in the same process and no Band. It sets `BRAIN_PROVIDER=fake`, `TARGET_MODEL=fake`, `TARGET_URL=inprocess`, `BAND_ENABLED=false` and `FAKE_DELAY_S=1` so the run is slow enough to watch. The detectors, guard policy and utility suite are the real ones. No keys needed.

</Tab>
<Tab value="Live">

```bash
pnpm dev
```

Lyzr agents (or a direct model), a real model behind the bot and every handoff posted to Band. Needs the keys below. Run `make -C backend probe` first to check the bot is breakable: it wants at least a 50% breach rate on v1.

</Tab>
<Tab value="Replay">

Pick any saved run on the dashboard and press **Replay**, or open `/dashboard?run=<run_id>&mode=replay`. Replays read `runs/<run_id>.jsonl` and need no keys. In the browser with no backend at all, `/dashboard?demo=live` plays the recorded run bundled with the site.

</Tab>
</Tabs>

## Commands

| Command | What it does |
| --- | --- |
| `pnpm bootstrap` | Installs everything, asks for keys, creates the Lyzr and Band agents, writes `.env` and checks every connection |
| `pnpm dev` | API, bot, dashboard and this site, live |
| `pnpm dev:offline` | The same with scripted agents and bot, no keys |
| `pnpm demo` | Records live runs until one passes the story check (round 1 breached, a patch vetoed, utility held), then saves `runs/demo_run.jsonl`. The committed one was promoted with `kavach.promote_demo` from a run whose first patch was approved |
| `make -C backend check-setup` | Re-runs only the connection checks |
| `make -C backend probe` | Is v1 breakable by your `TARGET_MODEL`? Needs at least 50% |
| `make -C backend band` | Checks the seven Band identities and posts a test message |
| `make -C backend smoke` | A full three-round offline run in the terminal |
| `make -C backend test` | The backend unit tests, offline |
| `pnpm deploy:site` | Builds this site, the docs and the dashboard demo and deploys them to Cloudflare. See [Deploy](/docs/deploy) |
