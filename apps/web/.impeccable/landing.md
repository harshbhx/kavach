## Direction contract

THESIS: The refund attack is a payment instrument. Kavach is security printing for agents: the same request clears on v1 and comes back VOID on v2. Refuses the dark neon "cybersecurity" hero and the split headline-plus-screenshot template.

OWN-WORLD: Indian cheque and banknote security printing. Cool security-paper green ground (#E6EFE9), intaglio green-black ink (#0E231C), guilloche line-work in teal, rubber-stamp rose (#C8203F) for breaches, teal (#0B6E7F) for held/void, ochre security thread (#B07D1A). Rozha One (Indian Type Foundry, engraved contrast, Devanagari) for display, Anek Latin for text, JetBrains Mono only for code and serial numbers. Microprint rules, perforations, MICR band, specimen cards.

STORY: Visitor sees a ₹54,999 refund slip signed by the bot, stamped PAID/BREACH; flips to guardrail v2 and sees the same slip VOID and held for a human. Then: the round as a passbook ledger, the five detectors as "know your note" security features, the utility trap as two stamped audits, the seven agents as authorised signatories, the sponsors as a printer's colophon, the quickstart on a counterfoil.

FIRST VIEWPORT: Paper band nav with logo and "Watch a run" ink button. Headline in Rozha One across 8 columns, subcopy and actions in the right 4. Below, the refund instrument spans the full container with v1/v2 index tabs on its top edge; stamp and VOID pantograph are the motion.

FORM: Security-printed document page, first on my list of seven (others: cricket scoreboard, Sivakasi cracker packaging, rangoli, govt challan, thermal receipt, terminal). seed: none (unavailable)
