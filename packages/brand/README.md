# @kavach/brand

The Guardrail K logo component and design tokens shared by `apps/web` and `apps/dashboard`.
Source of the artwork: `docs/assets/brand/` (see BRAND.md).

```tsx
import { KavachLogo } from '@kavach/brand'
import '@kavach/brand/tokens.css'
```

Tailwind v4: `@import "@kavach/brand/theme.css";` after `@import "tailwindcss";` gives `bg-kv-surface`, `text-kv-attack`, `font-display` and friends.
